Dein Lernweg

Eine SQL-Abfrage ist wie eine Antwort auf eine Frage an die Datenbank. Du musst nicht alles auf einmal können. Gehe die Schritte nacheinander durch.

1. Was soll angezeigt werden? → SELECT
2. Welche Datensätze sind gemeint? → WHERE
3. Soll gezählt werden? → COUNT()
4. Soll ein Durchschnitt berechnet werden? → AVG()
5. Soll für jede Sorte / jeden Tag einzeln gerechnet werden? → GROUP BY
6. Soll das Ergebnis sortiert werden? → ORDER BY
Merksatz: SELECT sagt, was du sehen willst. FROM sagt, woher die Daten kommen. WHERE grenzt die Zeilen ein. GROUP BY bildet Gruppen. ORDER BY sortiert das Ergebnis.

Lernschritt 1

SELECT und FROM – Was möchte ich sehen?

Beispiel-Frage in normaler Sprache:

„Zeige mir die Namen aller Eissorten.“
Schritt 1: „Namen“ ist die gesuchte Spalte → Name
Schritt 2: Eissorten stehen in der Tabelle → Produkt
Schritt 3: Spalte nach SELECT, Tabelle nach FROM.
SELECT Name
FROM Produkt;
Übersetzung:
„Zeige“ → SELECT
„die Spalte Name“ → Name
„aus der Tabelle Produkt“ → FROM Produkt

Lernschritt 2

WHERE – Welche Zeilen sollen ausgewählt werden?

Frage: „Zeige alle Kassenbelege vom 3. August 2026.“

1. Gewünschte Information: alle Spalten → SELECT *
2. Tabelle: Beleg → FROM Beleg
3. Einschränkung: Datum soll 2026-08-03 sein → WHERE Datum = '2026-08-03'
SELECT *
FROM Beleg
WHERE Datum = '2026-08-03';
Wichtig: Text und Datumswerte in dieser Datenbank werden mit einfachen Anführungszeichen geschrieben. Zahlen brauchen normalerweise keine Anführungszeichen.

Vergleichszeichen

ZeichenBedeutungBeispiel
=ist gleichPLZ = '10115'
>größer alsPreis > 5
<kleiner alsAnzahl < 3
>=größer oder gleichPreis >= 4
<>ungleichPLZ <> '10115'
Hilfe: Normale Sprache in WHERE übersetzen
  • „ist genau …“ → =
  • „größer als …“ → >
  • „kleiner als …“ → <
  • „ungleich …“ / „nicht …“ → <>
  • „und“ → AND (beide Bedingungen müssen stimmen)
  • „oder“ → OR (mindestens eine Bedingung muss stimmen)
Hilfe: Beispiel mit zwei Bedingungen
SELECT *
FROM Produktvariante
WHERE Preis > 4 AND Preis < 6;
Das Ergebnis enthält nur Varianten mit einem Preis zwischen 4 und 6 (ohne die Grenzwerte).
Lernschritt 3

COUNT() – Wie viele?

Frage: „Wie viele Kunden sind in der Datenbank gespeichert?“

1. „Wie viele“ bedeutet: zählen → COUNT()
2. Gezählt werden Kunden → Tabelle Kunde
3. Eine Anzahl ist ein einzelner Wert; SELECT COUNT(*) reicht.
SELECT COUNT(*)
FROM Kunde;

Erwartetes Ergebnis in dieser Datenbank: 50

COUNT(*) zählt alle Ergebniszeilen. Die Klammern gehören zur Funktion. Das Sternchen bedeutet hier: alle Zeilen zählen.
Hilfe: COUNT mit Bedingung
„Wie viele Belege gibt es vom 3. August 2026?“
SELECT COUNT(*)
FROM Beleg
WHERE Datum = '2026-08-03';
Erst werden durch WHERE die passenden Belege ausgewählt, danach zählt COUNT(*) diese Zeilen.
Hilfe: COUNT(DISTINCT …)Wenn du unterschiedliche Werte zählen möchtest, verwendest du DISTINCT:
SELECT COUNT(DISTINCT KundenID)
FROM Beleg;
So wird jede KundenID höchstens einmal gezählt.
⭐ Zusatzaufgabe für Schnelle · COUNT()

Wie viele Belege wurden am 03.08.2026 ausgestellt? Gib nur die Anzahl aus.

Starthilfe anzeigenCOUNT(*) zählt die Belege. Mit WHERE schränkst du auf das Datum ein.
Musterlösung anzeigen
SELECT COUNT(*)
FROM Beleg
WHERE Datum = '2026-08-03';
Lernschritt 4

AVG() – Wie hoch ist der Durchschnitt?

Frage: „Wie hoch ist der durchschnittliche Preis aller angelegten Produktvarianten?“

1. „durchschnittlich“ bedeutet: AVG()
2. Die Preise stehen in Produktvariante → Preis
3. Tabelle Produktvariante
SELECT AVG(Preis)
FROM Produktvariante;

Erwarteter Wert: ungefähr 4,89

COUNT zählt, AVG berechnet den Mittelwert. In AVG() muss eine Zahlenspalte stehen. AVG(Name) wäre deshalb nicht sinnvoll.
Hilfe: Durchschnitt nur für eine Auswahl
„Wie hoch ist der durchschnittliche Preis über 5 Euro?“
SELECT AVG(Preis)
FROM Produktvariante
WHERE Preis > 5;
WHERE wählt erst die passenden Varianten aus. AVG berechnet anschließend den Durchschnitt dieser Preise.
⭐ Zusatzaufgabe für Schnelle · AVG()

Wie hoch ist der durchschnittliche Preis der Produktvarianten, die mehr als 5 Euro kosten? Gib nur den Durchschnitt aus.

Starthilfe anzeigenAVG(Preis) berechnet den Durchschnitt. WHERE wählt vorher die Preise über 5 Euro aus.
Musterlösung anzeigen
SELECT AVG(Preis)
FROM Produktvariante
WHERE Preis > 5;
Lernschritt 5

GROUP BY – Für jede Gruppe einzeln rechnen

Frage: „Wie viele Kassenbelege gibt es pro Datum?“

Ohne GROUP BY würde COUNT(*) nur eine Gesamtzahl liefern. Mit GROUP BY wird für jedes Datum eine eigene Gruppe gebildet.

SELECT Datum, COUNT(*)
FROM Beleg
GROUP BY Datum;
1. Gruppiert werden soll nach Datum → SELECT Datum
2. Pro Gruppe zählen → COUNT(*)
3. Welche Spalte bildet die Gruppen? → GROUP BY Datum
Merksatz: GROUP BY beantwortet Fragen wie „pro …“, „je …“ oder „für jede/jeden …“.
Hilfe: Sprache erkennen
FormulierungSQL-Idee
Wie viele Belege pro Datum?GROUP BY Datum
Durchschnittspreis pro Produkt?GROUP BY Produkt
Verkaufte Menge je Variante?GROUP BY VarianteID
Hilfe: GROUP BY mit AVG
„Wie hoch ist der durchschnittliche Preis je Größe?“
SELECT GroesseID, AVG(Preis)
FROM Produktvariante
GROUP BY GroesseID;
Die Datenbank bildet eine Gruppe je GroesseID und berechnet für jede Gruppe einen eigenen Durchschnitt.
⭐ Zusatzaufgabe für Schnelle · GROUP BY

Wie viele Belege wurden jeweils von den einzelnen Kunden ausgestellt? Gib für jeden Kunden die Anzahl seiner Belege aus.

Starthilfe anzeigenMit GROUP BY KundenID bildest du eine Gruppe pro Kunde. COUNT(*) zählt die Belege jeder Gruppe.
Musterlösung anzeigen
SELECT COUNT(*)
FROM Beleg
GROUP BY KundenID;
Lernschritt 6

ORDER BY – Ergebnisse sortieren

Frage: „Zeige alle Produktvarianten, sortiert nach Preis vom niedrigsten zum höchsten Preis.“

SELECT VarianteID, Preis
FROM Produktvariante
ORDER BY Preis ASC;

ASC bedeutet aufsteigend (klein nach groß). DESC bedeutet absteigend (groß nach klein).

Wenn du keine Richtung angibst, sortiert SQLite standardmäßig aufsteigend. Für „höchster zuerst“, „absteigend“ oder „größter Wert zuerst“ verwendest du DESC.
Hilfe: Sortieren nach mehreren Spalten
SELECT Name, Vorname
FROM Kunde
ORDER BY Name ASC, Vorname ASC;
Erst wird nach Name sortiert. Bei gleichem Namen entscheidet Vorname.
⭐ Zusatzaufgabe für Schnelle · ORDER BY

Gib alle Produktvarianten aus und sortiere sie nach dem Preis vom höchsten zum niedrigsten.

Starthilfe anzeigenORDER BY Preis DESC sortiert die Preise absteigend.
Musterlösung anzeigen
SELECT VarianteID, Preis
FROM Produktvariante
ORDER BY Preis DESC;

Arbeitsweise: Lies die Frage. Markiere gedanklich Signalwörter. Entscheide, welche Tabelle und welche Spalten gebraucht werden. Schreibe die Abfrage vollständig. Öffne erst danach bei Bedarf die Hilfen oder die Musterlösung.

Aufgabe 7 · Kombination

Wie viele Belege gab es am 3. August 2026?

Schreibe eine vollständige Abfrage, die die Belege dieses Tages zählt. Hier musst du selbst entscheiden, welche SQL-Bausteine du kombinieren musst.

Hilfe 1: Frage zerlegen„Wie viele“ sagt dir, was berechnet werden soll. „Am 3. August 2026“ schränkt ein, welche Belege gezählt werden.
Hilfe 2: BausteineDu benötigst eine Zählfunktion und eine Bedingung für die Datumsspalte. Das Datum steht in der Datenbank im Format YYYY-MM-DD.
Musterlösung anzeigen
SELECT COUNT(*)
FROM Beleg
WHERE Datum = '2026-08-03';

So funktioniert die Prüfung: Deine SQL-Abfrage wird direkt in der mitgelieferten SQLite-Datenbank ausgeführt. Die App vergleicht das tatsächliche Ergebnis mit dem erwarteten Ergebnis. Bei einem Fehler erhältst du eine verständliche Rückmeldung. Die Datenbank bleibt unverändert: Es werden nur SELECT-Abfragen zugelassen.
